# IMO Website

A responsive communication-app landing page inspired by modern messaging and calling products. The interface presents product messaging, download actions, platform support, and supporting content.

## Tech Stack

- HTML5
- CSS3
- Responsive Web Design

## Highlights

- Product-focused hero section
- Download call to actions
- Platform support presentation
- Responsive layout
- Clean section-based structure

## Getting Started

Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/mdjihad-dev/Imo-website.git
cd Imo-website
```

## Project Focus

The project focuses on responsive frontend development, visual hierarchy, navigation, and building a product landing page from a visual design.
